# AI 写作学习平台

这是一个纯前端的写作学习平台，打造聚焦引导与启发的 AI 写作导师。用户不会直接获得文章成品，而是通过工具帮助构建思路、生成大纲、推荐素材和获取灵感提示。

平台功能：

- **仪表板**：显示学习进度、历史项目、写作小贴士。
- **启动引导 & 写作编辑**：进入“写作”标签后，选择文体（议论文、记叙文、学术论文），AI通过一系列结构化提问帮助你理清思路、搭建框架，完成基础大纲后可直接在编辑区开始写作。
- **大纲生成**：根据主题、类型、深度、目标读者自动生成文章结构，并提供写作指导。
- **素材推荐**：为当前主题提供示例资源（案例、名言、数据等），卡片中标注适用场景与引用示例，支持刷新与收藏偏好。
- **灵感提示**：写作过程中可主动点击“求助”获取提示；当编辑区停留超过3分钟未输入时，系统会自动分析并提供结构或延续建议，帮助你突破卡顿。
- **优化修补**：完成稿件后点击优化按钮，AI通过提问引导你发现逻辑、表达或结构问题，训练自我修改能力。
- **学习指南**：分阶段模块化课程，从写作基础到专项训练。
- **项目管理**：创建与跟踪写作项目，包括标题、描述和截止日期。

## 使用说明

1. **打开浏览器**并导航到本地文件夹中的 `index.html`。
2. 使用侧边栏切换不同模块。
3. 进入“写作”标签，选择文体后启动引导——系统会一步步提出问题帮助你搭建大纲，完成后即可在编辑区开始写作。
4. 你也可以在仪表板点击“开始写作”按钮直接进入引导模式。
5. 在任何写作过程中，可点击“求助”或等待卡顿自动触发灵感提示；写作完成后点击“优化修补”获取修改建议。
6. 在“**素材推荐**”填写相关主题词获取示例资源并可刷新或收藏。
7. 在“**大纲生成**”输入主题等信息，生成并查看结构（与写作流程互补）。
8. “**学习指南**”中选择章节查看详细课程内容。

## 技术栈

平台仅使用标准的 HTML、CSS 和 JavaScript，便于离线运行，无需服务器或构建工具。

如果需要部署到简单的静态托管（如 GitHub Pages），只需将文件推送到仓库即可。
