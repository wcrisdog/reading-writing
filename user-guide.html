快速开始

欢迎来到智引文思！

智引文思是一个智能写作辅助平台，使用AI技术帮助你快速生成优质文章。无论你是学生、作家还是内容创作者，这个平台都能显著提高你的写作效率。

核心功能一览

  • 启动引导 - 分步问答并快速生成写作计划大纲
  • 素材推荐 + 灵感提示 - 支持手动触发，也支持卡顿后自动触发灵感建议
  • 优化修补 - 对照结构、论证与表达给出可执行的修订建议
  • 手写识别与文本导入 - 支持图片 OCR，也支持 .txt / .docx 导入正文
  • 写作报告 + 成长档案 - 一键生成报告并累计你的能力变化轨迹

快速入门步骤

1

选择文体

在左侧选择你要写的文章类型：议论文、记叙文或学术论文

2

输入题目或主题

在标题栏输入文章的题目或主要主题

3

点击"启动引导"

让AI引导你一步步完成写作计划（通常需要5-10分钟）

4

开始写作

根据生成的大纲开始撰写，可随时使用灵感提示和素材推荐

5

优化修补

完成初稿后使用"优化修补"功能进行最后的打磨和改进

6

生成并查看报告

点击主界面中部的"写作报告"按钮，系统会自动生成并切换到报告视图

首次使用时，建议按照上述步骤完整体验一遍，这样可以更好地理解平台的所有功能。

功能介绍

📝 支持的文体

文体 适用场景 建议字数 结构
议论文 高中考试、学术讨论 800字 引入 → 论点 → 论据 → 总结
记叙文 故事叙述、个人经验 600字 背景 → 发展 → 高潮 → 结尾
学术论文 大学研究、专业写作 无限制 摘要 → 引言 → 正文 → 结论

🌍 多语言支持

平台完全支持中文和英文，所有界面和提示都会根据你的选择自动切换语言。

  • 中文界面和中文写作指导
  • 英文界面和英文写作建议
  • 自动保存语言偏好设置

💾 自动保存

你可以在页面右上角看到一个"自动保存"开关。启用后，你的所有内容会自动保存到浏览器的本地存储，即使刷新页面也不会丢失。

📊 实时统计

在页面底部可以看到实时的写作统计：

  • 字数统计（中文按字数统计，英文按单词统计）
  • 段落数统计
  • 进度百分比（相对于目标字数）
  • 写作时长与当前速度

📈 写作报告与成长档案

你可以点击主界面中部的"写作报告"按钮生成并查看报告。

  • 报告包含六维评分、综合评价、工具使用记录和卡顿分析
  • AI评分失败时会自动降级为本地评分，保证报告可用
  • 成长档案会在侧边栏持续积累并展示你的能力变化

🖼️ 手写识别与文件导入

编辑区右上角提供"上传手写作文"入口，支持以下格式：

  • 图片文件（手写 OCR 识别）
  • .txt（直接读取文本）
  • .docx（提取正文文本后写入）

当写作框已有内容时，会弹出"覆盖写入 / 追加写入"二选一对话框。

不同文体有不同的目标字数，但你可以自定义目标字数以适应具体需求。

详细教程

如何使用启动引导（完整流程）

启动引导是智引文思最核心的功能，它会通过5个步骤（其中第3步为AI反馈）帮助你规划整篇文章。

📌 步骤1-2：核心观点和论证角度（议论文为例）

系统会问你两个关键问题：

  • 你这篇文章的核心观点是什么？
  • 你计划从哪几个角度来论证？

你的回答越清晰具体，AI生成的大纲就越有针对性。

📌 步骤3：AI反馈和建议

AI会根据你的回答，筛选和补充论证角度。你可以：

  • 点击"满意，继续"接受建议
  • 点击"需要修改"提出你的想法，AI会重新生成
  • 点击"返回上一步"修改之前的回答

📌 步骤4-5：反驳和素材

最后两步帮你：

  • 思考可能的反对意见
  • 列举你想使用的名言、故事或数据

📌 完成引导后

AI会自动生成一份完整的写作大纲，包含：

  • 各部分的建议内容和篇幅
  • 推荐的素材位置
  • 关键论证点的提示

如何使用素材推荐

  1. 在标题栏输入你的文章主题
  2. 点击"获取素材"按钮
  3. AI会推荐相关的名言、例子、数据等
  4. 点击"✓ 使用"将素材插入到当前编辑位置
  5. 点击"查看详情"了解素材的使用建议
如果AI推荐的素材不满意，可以点击"换一批"刷新推荐列表。

如何使用灵感提示

当你在写作过程中卡顿时，可以：

  1. 点击"获取灵感"按钮
  2. AI会分析你已写内容的长度和进度
  3. 根据情况提供不同的建议：
    • 如果还在起初阶段：建议如何更清晰地表述观点
    • 如果进度过半：建议如何充实论据和保持逻辑
    • 如果快要完成：建议如何总结升华

如何文体切换

修改文体时，你的所有当前内容（标题、正文、AI生成内容、报告内容与报告缓存等）都会被清除。系统会提示你确认修改。

切换步骤：

  1. 点击顶部的文体按钮（议论文/记叙文/学术论文）
  2. 系统提示你是否确认修改
  3. 点击"确定"后，所有内容会被清除，文体会切换
  4. 模板会自动更新，重新开始新的创作

功能详解

右下角面板说明

右下角有两个标签页，可以在"写作计划"和"优化修补"之间切换：

📋 写作计划标签

显示AI生成的完整写作大纲，包含：

  • 各部分的标题和内容建议
  • 推荐字数和篇幅分配
  • 素材使用建议

🔍 优化修补标签

完成初稿后，可以点击"优化修补"来：

  • 获取AI的专业修改建议
  • 提高文章的逻辑性和说服力
  • 改进表达方式和用词

放大查看功能

无论你在哪个标签页，都可以点击"放大"按钮在全屏模式下查看完整内容。这对于长篇幅的大纲特别有帮助。

原始题目输入

如果你有一道完整的考试题目或写作任务，可以：

  1. 点击"📝 输入原始题目"按钮
  2. 粘贴完整的题目内容
  3. 点击"提交"保存
  4. 之后启动引导时，AI会参考这个原始题目生成更精准的大纲
这个功能特别适合高考或考试准备，可以确保你的大纲完全符合题目要求。

上传手写作文（OCR）

在编辑区右上角点击"上传手写作文"后，可选择图片、.txt、.docx。

  1. 选择文件并等待识别/解析完成
  2. 若当前写作框已有内容，选择"覆盖写入"或"追加写入"
  3. 识别失败时，系统会提示原因并询问是否重试

优化修补的详细流程

点击"优化修补"后，系统会逐一提出以下问题：

  • 观点和论据是否充分对应？
  • 论据的可信度和说服力？
  • 反方观点如何驳斥？
  • 开头和结尾是否呼应？
  • 句子之间的逻辑关系是否清晰？

每个问题都有详细的优化建议，你可以根据建议逐一改进文章。

中级技巧

🎯 如何写出更好的启动引导回答

启动引导的质量直接影响最终的大纲质量。here's how to答得更好：

核心观点要清晰明确

不要说"我觉得教育很重要"，而是说"教育的最大价值在于培养独立思考能力，而不仅仅是传授知识"。

论证角度要具体有序

列举3-5个具体角度后，AI会更容易理解你的想法。比如"个人成长角度"比"各种角度"更有帮助。

提前准备素材

如果你已经想到了精妙的例子或名言，在第5步输入它们。AI会在大纲中提示你在什么位置使用。

充分利用AI反馈

不要急着接受AI的第一个建议，试试点击"需要修改"来提出你的想法。多互动会得到更个性化的建议。

💡 写作过程中的技巧

合理使用灵感提示

不是只在卡顿时使用。定期（比如每500字后）点击灵感提示可以：

  • 确保你的方向没有偏离大纲
  • 获得改进接下来段落的具体建议
  • 保持写作的流畅性

分段完成初稿

不要期望一口气写完全文。建议：

  1. 每天完成一个主要段落
  2. 保持"自动保存"开启，确保内容持续写入本地
  3. 偶尔点击"获取灵感"检查进度和方向

有效利用素材推荐

素材不仅是为了充实内容，更重要的是：

  • 通过具体的例子论证观点
  • 增加文章的说服力和可读性
  • 引发读者的共鸣

🔧 高级自定义技巧

自定义目标字数

右侧有一个"目标字数"下拉菜单。如果预设字数不符合你的需求，你可以：

  1. 点击下拉菜单
  2. 输入自己的目标字数
  3. 实时显示当前进度百分比

保留多个版本

如果你想保留不同阶段的版本（如修改前/修改后），建议：

  1. 将阶段稿复制到本地文档保存
  2. 使用"上传手写作文"导入 .txt / .docx 回填版本
  3. 必要时使用"覆盖写入"快速切换版本进行比较

充分利用多语言特性

如果你需要同时用中文和英文写作：

  • 完成中文初稿后，点击"导出"
  • 切换到英文界面（选择English）
  • 点击"清空"重新开始英文版本
  • 系统会自动提供英文的引导和建议

常见问题解答

我的文章内容会被保存吗？

是的！智引文思支持本地自动保存：

  • 本地自动保存：启用"自动保存"后，内容会持续写入浏览器本地存储。
  • 最近写作恢复：可在个人主页点击"最近写作"新开主界面并恢复上次内容。

注意：本地保存内容只在当前浏览器可用。切换浏览器或清理缓存会导致内容丢失，建议重要稿件自行备份。

AI生成的内容可靠吗？

智引文思的AI由专业的大语言模型（如通义千问）驱动，经过教育领域的调优。生成的内容通常是：

  • ✓ 逻辑清晰、结构合理
  • ✓ 符合中文/英文写作规范
  • ✓ 有教育价值和可读性

但是，AI并不完美。建议你：

  • 将AI建议作为参考而非绝对真理
  • 根据你的实际知识和观点调整内容
  • 对于事实性内容（如数据、历史事件），自己验证
如果修改文体，之前的内容会丢失吗？

是的——修改文体时，所有当前内容都会被清除。这包括：

  • 标题和正文内容
  • AI生成的大纲
  • 已生成的写作报告与报告缓存
  • 所有运行时状态

在修改文体前系统会提示确认。若需保留内容，请先自行复制备份。

启动引导一定要按照问题顺序回答吗？

不一定。引导系统支持：

  • ✓ 回到上一步修改之前的回答
  • ✓ 多次与AI互动获得最满意的建议
  • ✓ 跳过某些步骤直接继续

不过，按照顺序完成通常能得到质量最好的大纲。

如何获得最好的AI建议？

AI的输出取决于你的输入质量。要获得最好的建议：

  • 📝 被尽可能清晰和具体地表述你的想法
  • 📝 提供具体的例子而非笼统的概念
  • 📝 说明你的目标受众和写作目的
  • 📝 充分利用"需要修改"功能与AI互动
  • 📝 提前准备相关的素材和想法
平台支持离线使用吗？

不完全支持。平台的离线能力有限：

  • ✓ 离线可用：基本的写作和编辑功能
  • ✓ 离线可用：查看已保存的本地内容
  • △ 建议联网：AI功能（启动引导、素材推荐、灵感提示、优化修补、AI评分）
  • ✓ 降级可用：AI不可用时，灵感提示/评分会回退为本地结果
如何重置平台或清除所有数据？

如果你想完全重新开始：

  1. 点击"清空"按钮可以清除当前内容与已生成结果
  2. 点击"清除浏览器缓存"可以完全清除所有本地保存的数据

警告：这些操作不可撤销，请确保你已备份重要稿件。

为什么有时候AI功能会很慢？

AI功能可能变慢的原因包括：

  • 🔌 网络连接：请检查你的网络速度
  • 🔌 AI服务器负载：在高峰时段可能较慢
  • 🔌 输入内容过长：非常长的内容会需要更多处理时间

如果问题持续，可以尝试：

  • 刷新页面
  • 稍后再试
  • OCR 场景下更换更清晰、更小的图片，或改用 .txt/.docx 上传
  • 检查浏览器控制台是否有错误信息
手写识别失败怎么办？

当 OCR 失败时，系统会提示失败原因并询问是否重试。你也可以主动优化输入：

  • 保证图片清晰、字迹居中、光线充足
  • 尽量减少阴影和背景杂色
  • 优先上传 .txt 或 .docx 以避免识别误差
